# tools

Small personal tools for day-to-day dev work. Each folder is self-contained and has its own README.

| Folder | What it is |
| --- | --- |
| [`swiftbar/`](swiftbar/) | macOS menu bar plugins for [SwiftBar](https://github.com/swiftbar/SwiftBar) |
| [`gh-stack-share/`](gh-stack-share/) | Chrome extension adding a share button to GitHub's stacked-PR modal |

## Local config stays local

Credentials and anything about other people (team lists, emails, reporting lines) live in gitignored files next to the tool that reads them. Only `*.example*` files are committed. Copy one and fill it in to get started.
